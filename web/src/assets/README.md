# Workspace artwork

The light/dark Shelldon logos and quiz/semantic mascots are the supplied project artwork, bundled unchanged from the design handoff. Fonts and their licenses are documented in `fonts/README.md`.

`favicon.png` and `favicon-64.png` are transparent 32px/64px browser icons using a simplified turtle head derived from the supplied logo. The original high-resolution generated image is not bundled; the app serves these optimized source assets locally in development and the embedded release.

The Material Symbols in `material/` come from the handoff's Google Material Symbols collection, licensed under Apache 2.0 (`material/LICENSE.txt`). They are bundled locally and used as current-color masks; no icon font or remote asset service is loaded. Complete icon/font licenses are bundled as assets and linked from the entry page's Asset licenses disclosure.
