# Workspace artwork

The light/dark Shelldon logos and quiz/semantic mascots are the supplied project artwork, bundled unchanged from the design handoff. Fonts and their licenses are documented in `fonts/README.md`.

The four Material Symbols in `material/` come from the handoff's Google Material Symbols collection, licensed under Apache 2.0 (`material/LICENSE`). They are bundled locally and used as current-color masks; no icon font or remote asset service is loaded.
